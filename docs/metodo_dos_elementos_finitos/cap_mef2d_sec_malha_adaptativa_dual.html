2.4 Malha adaptativa dual

Em construção

Podemos desenvolver um método de malha adaptativa para minimizar o erro de uma quantidade de interesse, dada por um funcional linear ℳ:V→ℝ, onde V é o espaço de soluções do problema fraco. Aqui, vamos seguir trabalhando com o problema modelo (2.37): encontrar u∈V0 tal que

a⁢(u,v)=L⁢(v),∀v∈V0, (2.128)

onde V0=H01⁢(Ω) e Ω=[0,1]2. Como exemplo de funcional linear, vamos usar a média da solução u no domínio Ω, ou seja,

ℳ⁢(u)=1|Ω|⁢∫Ωu⁢𝑑x. (2.129)

Tendo em vista que o funcional objetivo é linear, temos que

ℳ⁢(e)=ℳ⁢(u−uh)=ℳ⁢(u)−ℳ⁢(uh), (2.130)

onde e=u−uh é o erro entre a solução exata u e a solução de elementos finitos uh. Introduzimos o problema dual (ou problema adjunto) associado a ℳ: encontrar z∈V0 tal que

a⁢(v,z)=ℳ⁢(v),∀v∈V0. (2.131)

Com isso, temos

ℳ⁢(e)=a⁢(e,z) (2.132)
=a(e,z−zh)+a(e,zh) (2.133)
=a(u−uh,z−zh) (2.134)
=a(u,z−zh)−a(uh,z−zh) (2.135)
=L(z−zh)−a(uh,z−zh). (2.136)

Para o caso do problema modelo, temos

ℳ⁢(e)=∫Ωf⁢(z−zh)⁢𝑑x−∫Ω∇uh⋅∇(z−zh)⁡d⁢x (2.137)
=∑K∈𝒦∫K(f+Δuh)(z−zh)dx
+12⁢∑E∈ℰI∫E[𝒏⋅∇uh]⁢(z−zh)⁢𝑑s, (2.138)

que nos fornece uma forma de representação do erro.

Teorema 2.4.1.(Estimativa a posteriori dual)

A solução uh do problema de elementos finitos (2.42) satisfaz

ℳ⁢(e)≤C⁢∑K∈𝒦ηK⁢(uh,z), (2.139)

onde o elemento residual ηK⁢(uh,z)=ρK⁢(uh)⁢ωK⁢(z) é definido por

ρK⁢(uh)=‖f+Δ⁢uh‖L2⁢(K)+12⁢hK1/2⁢‖[𝒏⋅∇uh]‖L2⁢(∂K∖∂Ω), (2.140)
ωK⁢(z)=hK2⁢‖D2⁢z‖L2⁢(K). (2.141)
