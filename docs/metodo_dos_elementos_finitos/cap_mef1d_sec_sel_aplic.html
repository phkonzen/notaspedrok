1.4 Seleção de aplicações

1.4.1 Problema não-linear

Como um exemplo de aplicação do método de elementos finitos na solução de equações diferenciais parciais não-lineares, consideramos o problema de Troesch

u′′=μ⁢sinh⁡(μ⁢u),x∈(0,1), (1.189)
u⁢(0)=0,u⁢(1)=1, (1.190)

onde μ>0 é um parâmetro.

A formulação fraca deste problema consiste em: encontrar u∈V:={v∈H1⁢(I);v⁢(0)=0,v⁢(1)=1} tal que

F⁢(u,v):=L⁢(v)−a⁢(u,v)=0,∀v∈V0, (1.191)

onde, V0={v∈H1⁢(I);v⁢(0)=0,v⁢(1)=0} e as formas bilinear a⁢(⋅,⋅) e linear L⁢(⋅) são dadas por

a⁢(u,v):=∫01u′⁢v′⁢𝑑x, (1.192)
L⁢(v):=−∫01μ⁢sinh⁡(μ⁢u)⁢v⁢𝑑x. (1.193)

A formulação de elementos finitos deste problema consiste em: encontrar uh∈Vh:={vh∈P1⁢(I);vh⁢(0)=0,vh⁢(1)=1} tal que

a⁢(uh,vh)=−L⁢(vh),∀vh∈Vh⁢,0, (1.194)

onde Vh⁢,0={vh∈P1⁢(I);vh⁢(0)=0,vh⁢(1)=0}.

1.4.2 EDP evolutiva

Vamos estudar a aplicação do método de elementos finitos na solução de equações diferenciais parciais evolutivas no tempo. Para isso, consideramos como problema modelo a equação do calor com dadas condição inicial e condições de contorno de Dirichlet homogêneas

ut=α⁢ux⁢x+f,(t,x)∈(0,tf]×(a,b), (1.195)
u⁢(0,x)=u0⁢(x),x∈[a,b], (1.196)
u⁢(t,a)=u⁢(t,b)=0,t∈[0,tf], (1.197)

onde f=f⁢(t,x) denota uma dada fonte, α>0 é a difusividade e u0 é a condição inicial e tf>0 é o tempo final.

Antes de elaborarmos a formulação fraca, vamos assumir uma discretização do tempo. Consideramos os nt+1 tempos discretos t(k)=k⁢ht, passo no tempo ht=tf/nt, k=0,1,2,…,nt. Seguindo esquema θ e denotando u~(k)≈u⁢(t(k),x) e f(k)=f⁢(t(k),x), o problema pode ser aproximado pela iteração

u~(k+1)−u~(k)ht=θ⁢(α⁢u~x⁢x(k+1)+f(k+1))
(1−θ)⁢(α⁢u~x⁢x(k)+f(k)), (1.198)
u~(k+1)⁢(a)=u~(k+1)⁢(b)=0, (1.199)

para k=0,1,2,…,nt e u~(0)=u0. Ou seja, cada iteração k se resume ao seguinte problema de valores de contorno

−α⁢θ⁢u~x⁢x+1ht⁢u~=1ht⁢u~0+(1−θ)⁢α⁢u~x⁢x0
(1−θ)⁢f0+θ⁢f, (1.200)
u~⁢(a)=u~⁢(b)=0, (1.201)

onde u~0=u~(k) e u~=u~(k+1) para fins de simplificação da notação121212Análogo para f(k) e f(k+1)..

A formulação fraca deste problema de valores de contorno consiste em: encontrar u~∈V0:=H01⁢(a,b) tal que

a⁢(u~,v)=L⁢(v),∀v∈V0, (1.202)

onde

a⁢(u~,v):=θ⁢∫abα⁢u~′⁢v′⁢𝑑x+∫ab1ht⁢u~⁢v⁢𝑑x, (1.203)
L⁢(v):=(θ−1)⁢∫abα⁢u~0′⁢v′⁢𝑑x+∫ab1ht⁢u~0⁢v⁢𝑑x
θ⁢∫abf⁢v⁢𝑑x+(1−θ)⁢∫abf0⁢v⁢𝑑x. (1.204)

Logo, a formulação de elementos finitos P1 deste problema consiste em: encontrar u~h∈Vh⁢,0:={vh∈P1⁢(a,b);vh⁢(a)=0,vh⁢(b)=0} tal que

a⁢(u~h,vh)=L⁢(vh),∀vh∈Vh⁢,0. (1.205)
Exemplo 1.4.1.

Consideremos o problema de calor

ut=ux⁢x+f,(t,x)∈(0,1]×(0,1), (1.206)
u⁢(0,x)=sen⁡(π⁢x),x∈[0,1], (1.207)
u⁢(t⁢,0)=u⁢(t⁢,1)=0,t∈[0,1], (1.208)

onde f⁢(t,x)=(π2−1)⁢e−t⁢sen⁡(π⁢x). A solução analítica deste problema é u⁢(t,x)=e−t⁢sen⁡(π⁢x). O Código 11 a seguir implementa a aproximação por elementos finitos deste problema. 1.4.3 Sistema de equações

Consideramos o seguinte problema de equações diferenciais ordinárias com valores de contorno

−u0′′+u1=f0,∀x∈I=(iL,iR) (1.209)
−u1′′−u0=f1,∀x∈I (1.210)
u0⁢(iL)=u0⁢L,u0⁢(iR)=u0⁢R, (1.211)
u1⁢(iL)=u1⁢L,u1⁢(iR)=u1⁢R, (1.212)

onde f0, f1, u0⁢L, u0⁢R, u1⁢L, u1⁢R são dados.

Para construirmos uma aproximação por elementos finitos podemos tomar o seguinte problema fraco associado: encontrar 𝒖=(u0,u1)∈𝒰:=U0×U1 tal que

a⁢(𝒖,𝒗)=L⁢(𝒗),∀𝒗=(v0,v1)∈𝒱0:=V0×V0, (1.213)

onde U0={v∈H1⁢(I);v⁢(iL)=u0⁢L,v⁢(iR)=u0⁢R}, U1={v∈H1⁢(I);v⁢(iL)=u1⁢L,v⁢(iR)=u1⁢R}, V0={v∈H1⁢(I);v⁢(0)=v⁢(L)=0}, a forma bilinear é

a⁢(𝒖,𝒗)=∫Iu0′⁢v0′⁢𝑑x+∫Iu1′⁢v1′⁢𝑑x+∫Iu1⁢v0⁢𝑑x−∫Iu0⁢v1⁢𝑑x (1.214)

e a forma linear é

L⁢(𝒗)=∫If0⁢v0⁢𝑑x+∫If1⁢v1⁢𝑑x. (1.215)

Então, o problema de elementos finitos associado no espaço das funções lineares por partes lê-se: encontrar 𝒖h=(uh⁢0,uh⁢1)∈𝒰h:=Uh⁢0×Uh⁢1 tal que

a⁢(𝒖h,𝒗h)=L⁢(𝒗h),∀𝒗h=(vh⁢0,vh⁢1)∈𝒱0:=Vh⁢0×Vh⁢0, (1.216)

onde Uh⁢0={vh∈P1⁢(I);vh⁢(iL)=u0⁢L,vh⁢(iR)=u0⁢R}, Uh⁢1={vh∈P1⁢(I);vh⁢(iL)=u1⁢L,vh⁢(L)=u1⁢R}, Vh⁢0={vh∈P1⁢(I);vh⁢(0)=vh⁢(L)=0}.

Exemplo 1.4.2.

Consideremos o seguinte problema de valor de contorno

−u0′′+u1=sen⁡(x)+cos⁡(x),∀x∈(−π,π) (1.217)
−u1′′−u0=cos⁡(x)−sin⁡(x),∀x∈(−π,π) (1.218)
u0⁢(−π)=0,u0⁢(π)=0, (1.219)
u1⁢(−π)=−1,u1⁢(π)=−1. (1.220)

Sua solução analítica é u0⁢(x)=sen⁡(x) e u1⁢(x)=cos⁡(x). O Código 12 a seguir implementa a aproximação por elementos finitos deste problema. 1.4.4 Exercícios

E. 1.4.1.

Obtenha uma aproximação por elementos finitos da solução do seguinte problema não-linear de Poisson131313Siméon Denis Poisson, 1781 - 1840, matemático francês. Fonte: Wikipédia: Siméon Denis Poisson.

−(q⁢(u)⁢u′)′=π2⁢(3⁢sen3⁡(π⁢x)−sen⁡(π⁢x)),x∈(0,1), (1.221)
u⁢(0)=0,u⁢(1)=0, (1.222)

onde q⁢(u)=1+u2. Faça o esboço dos gráficos da solução analítica u⁢(x)=sen⁡(π⁢x) e da sua aproximação de elementos finitos. Então, faça uma análise da convergência de malha e verifique as taxas de convergência dos erros ‖u−uh‖L2 e ‖(u−uh)′‖L2.

E. 1.4.2.

Considere o problema de Fisher

−ut=ux⁢x+λ⁢u⁢(1−u),(t,x)∈(0,tf]×(0,1), (1.223)
u⁢(0,x)=(1+eλ6⁢x)−2,x∈[0,1], (1.224)
ux⁢(t⁢,0)=(1+e−56⁢λ⁢t)−2,t∈[0,tf], (1.225)
ux⁢(t⁢,1)=(1+eλ⁢6−56⁢λ⁢t)−2,t∈[0,tf], (1.226)

onde λ=1 (taxa de crescimento populacional) e tf=1 (tempo final). A solução analítica deste problema é

u⁢(t,x)=(1+eλ6⁢x−56⁢λ⁢t)−2. (1.227)

Faça três códigos de elementos finitos para este problema utilizando os seguintes esquemas de tempo:

  1. a)

    θ=0 (esquema de Euler explícito);

  2. b)

    θ=1 (esquema de Euler implícito);

  3. c)

    θ=0.5 (esquema de Crank-Nicolson).

Em cada caso, faça o esboço dos gráficos da solução analítica e da sua aproximação de elementos finitos. Então, faça uma análise da convergência das malhas espacial e temporal.

E. 1.4.3.

Considere o seguinte problema não-linear de Calor

ut=(q⁢(u)⁢ux)+f,(t,x)∈(0,tf]×(0,1), (1.228)
u⁢(0,x)=sen⁡(π⁢x),x∈[0,1], (1.229)
u⁢(t⁢,0)=u⁢(t⁢,1)=0,t∈[0,tf], (1.230)

onde q⁢(u)=1+u2, a fonte é

f⁢(t,x)=(π2−1)⁢e−t⁢s+e−3⁢t⁢s⁢(3⁢s2−2), (1.231)

com s:=sin⁡(π⁢x). A solução analítica deste problema é u⁢(t,x)=e−t⁢sen⁡(π⁢x). Faça três códigos de elementos finitos para este problema utilizando os seguintes esquemas de tempo:

  1. a)

    Runge-Kutta de ordem 4 (RK4 - explícito);

  2. b)

    Método de Adams-Moulton de ordem 2 (A-M-2);

  3. c)

    Método preditor-corretor de Adams-Bashforth-Moulton de ordem 2 (A-B-M-2);

Quais dos códigos mostrou-se mais eficiente?

E. 1.4.4.

Estude aproximações por elementos finitos para o seguinte problema de Burgers

ut+uux=νux⁢x,(t,x)∈(0,1]×(−1,1), (1.232)
u⁢(0,x)=2⁢ν⁢π⁢sen⁡(π⁢x)2+cos⁡(π⁢x),x∈[−1,1], (1.233)
u⁢(t,−1)=u⁢(t⁢,1)=0,t∈[0,1], (1.234)

para ν=0.1,0.01,0.001. A solução analítica deste problema é

u⁢(t,x)=2⁢ν⁢π⁢e−ν⁢π2⁢t⁢sen⁡(π⁢x)2+e−ν⁢π2⁢t⁢cos⁡(π⁢x). (1.235)
E. 1.4.5.

Estude aproximações por elementos finitos para o seguinte problema de Burgers

ut+uux=νux⁢x,(t,x)∈(0,1]×(−1,1), (1.236)
u⁢(0,x)=−sen⁡(π⁢x),x∈[−1,1], (1.237)
u⁢(t,−1)=u⁢(t⁢,1)=0,t∈[0,1], (1.238)

onde ν>0. Para ν=0.01/π, a solução analítica é

u⁢(t,x)=−−∫−∞∞sen⁡(π⁢(x−η))⁢f⁢(x−η)⁢e−η24⁢ν⁢t⁢d⁢η∫−∞∞f⁢(x−η)⁢e−η24⁢ν⁢t⁢𝑑η, (1.239)

onde f⁢(y)=ecos⁡(π⁢y)2⁢π⁢ν. Estude também o comportamento das aproximações por elementos finitos para ν cada vez menor.

E. 1.4.6.

Estude aproximações por elementos finitos para o seguinte problema de Burgers

ut+uux=νux⁢x,(t,x)∈(0,1]×(−1,1), (1.240)
u⁢(0,x)=2⁢sign⁡(x),x∈[−1,1], (1.241)
u⁢(t,−1)=ua⁢(t,−1),u⁢(t⁢,1)=ua⁢(t⁢,1),t∈[0,1], (1.242)

onde ν>0. Para ν=1, a solução analítica é

ua⁢(t,x)=2⁢G⁢(t,x)−G⁢(t,−x)G⁢(t,x)+G⁢(t,−x), (1.243)

onde G⁢(t,x)=12⁢et−x⁢erfc⁡(2⁢t−x2⁢t). Estude também o comportamento das aproximações por elementos finitos para ν cada vez menor.

E. 1.4.7.

Estude aproximações por elementos finitos para o seguinte problema de Solow-Swan

∂K∂t=s⁢(x)⁢A⁢Kϕ⁢L1−ϕ⁢(x)−δ⁢K+d⁢∂2K∂x2,x∈(0,l),t>0, (1.244)
K⁢(t,x)=K0⁢(x),x∈Ω=[0,l],t=0, (1.245)
∂K∂x=0,x∈∂Ω={0,l},t>0. (1.246)

para o caso em que l≡10, T≡10, ϕ≡1/3, δ⁢(x)≡0.05, A⁢(x)≡1, d⁢(x)≡0.25, L⁢(x)=1+0.3⁢x2⁢[1−cos⁡(4⁢π⁢x/l)], k0⁢(x)=cos4⁡(π⁢x/(2⁢l)−π/2), and s⁢(x)=0.2⁢cos4⁡(π⁢x/(2⁢l)).

E. 1.4.8.

Estude aproximações por elementos finitos para o seguinte sistema de equações de difusão-reação

−ε0⁢u0′′+a⁢u0+b⁢u1=f0,x∈(0,1), (1.247)
−ε1⁢u1′′+c⁢u0+d⁢u1=f1,x∈(0,1), (1.248)
u0⁢(0)=u0⁢(1)=0, (1.249)
u1′⁢(0)=u1′⁢(1)=0, (1.250)

onde ε0,ε1>0 são os coeficientes de difusão, a,b,c,d são os coeficientes de reação, e f0,f1 são as fontes. Como estudo de caso, considere ε0=1, ε1=2, a=1, b=−1, c=−1, d=2. Para a solução manufaturada u0⁢(x)=sen⁡(π⁢x), u1⁢(x)=cos⁡(π⁢x), as fontes são

f0⁢(x)=π2⁢sen⁡(π⁢x)−2⁢cos⁡(π⁢(x+1/4)), (1.251)
f1⁢(x)=−sen⁡(π⁢x)+2⁢cos⁡(π⁢x)+2⁢π2⁢cos⁡(π⁢x). (1.252)

Estude a convergência de malha e verifique as taxas de convergência dos erros ‖u0−uh⁢0‖L2, ‖(u0−uh⁢0)′‖L2, ‖u1−uh⁢1‖L2 e ‖(u1−uh⁢1)′‖L2.

E. 1.4.9.

Estude aproximações por elementos finitos para o seguinte sistema de equações de difusão-reação não-linear

−ε0⁢u0′′−u0+u02⁢u1=f0,x∈(0,1), (1.253)
−ε1⁢u1′′−u0⁢u12=f1,x∈(0,1), (1.254)
u0′⁢(0)=π,u0′⁢(1)=−π, (1.255)
u1⁢(0)=1,u1⁢(1)=1. (1.256)

onde ε0,ε1>0 são os coeficientes de difusão, e f0,f1 são as fontes. Como estudo de caso, considere ε0=1, ε1=10, e as seguintes fontes

f0⁢(x)=(sen⁡(π⁢x)⁢cos⁡(2⁢π⁢x)−1+π2)⁢sen⁡(π⁢x), (1.257)
f1⁢(x)=(−sen⁡(π⁢x)⁢cos⁡(2⁢π⁢x)+40⁢π2)⁢cos⁡(2⁢π⁢x). (1.258)

A solução analítica deste problema é u0⁢(x)=sen⁡(π⁢x) e u1⁢(x)=cos⁡(2⁢π⁢x). Estude a convergência de malha e verifique as taxas de convergência dos erros ‖u0−uh⁢0‖L2, ‖(u0−uh⁢0)′‖L2, ‖u1−uh⁢1‖L2 e ‖(u1−uh⁢1)′‖L2.

E. 1.4.10.

Estude aproximações por elementos finitos para o seguinte problema de FitzHugh-Nagumo

ut=Du⁢ux⁢x+λ⁢u−u3−v−κ,(t,x)∈(0,tf]×(−L,L), (1.259)
vt=Dv⁢vx⁢x+u−v,(t,x)∈(0,tf]×(−L,L), (1.260)
ux⁢(t,−L)=ux⁢(t,L)=0,t∈[0,tf], (1.261)
vx⁢(t,−L)=vx⁢(t,L)=0,t∈[0,tf], (1.262)
u⁢(0,x)=e−x2,v⁢(0,x)=0,x∈[−L,L], (1.263)

onde Du,Dv>0 são os coeficientes de difusão, λ é o parâmetro de excitabilidade, e κ é o parâmetro de estímulo. Obtenha uma solução precisa para Du=0.1, Dv=0.01, λ=1, κ=0, L=10 e tf=10.
