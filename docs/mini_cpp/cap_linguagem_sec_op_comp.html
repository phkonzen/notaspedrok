2.4 Operadores de comparação elementares

Os operadores de comparação elementares são

  • == igual a

  • != diferente de

  • > maior que

  • < menor que

  • >= maior ou igual que

  • <= menor ou igual que

Estes operadores retornam os valores lógicos true (verdadeiro, 1) ou false (falso, 0). Variáveis do tipo bool (variáveis booleanas444George Boole, 1815 - 1864, matemático britânico. Fonte: Wikipédia: George Boole.) são usadas para armazenar valores lógicos.
