2.1 Classes de objetos básicos

Python é uma linguagem de programação dinâmica em que os objetos são associados automaticamente a classes de dados ao receberem um valor. Por exemplo, consideremos as seguintes instruções:

⬇
1x = 2
2y = x * 3.0

Na primeira instrução, a variável x recebe o valor inteiro 2 e, então, é armazenada na memória do computador como um objeto da classe int (número inteiro111Python 3 pode armazenar inteiros de qualquer tamanho, limitado apenas pela memória disponível.). Na segunda instrução, y recebe o valor decimal 6.0 (resultado de 2×3.0) e é armazenada como um objeto da classe float (ponto flutuante222Um número da classe float em Python 3 utiliza 64 bits. Isso corresponde ao padrão IEEE 754 para representação de números de ponto flutuante de dupla precisão.). Podemos verificar isso com as seguintes instruções:

⬇
1print(x)
⬇
2
⬇
1print(y)
⬇
6.0
⬇
1print(type(x), type(y))
⬇
<class 'int'> <class 'float'>
Observação 2.1.1.(Comentários e continuação de linha)

Códigos Python admitem comentários e continuação de linha, como no seguinte exemplo:

⬇
1# isto é um comentário
2s = "isto é uma \
3string"
4print(s)
⬇
isto é uma string
⬇
1type(s)
⬇
<class 'str'>
Observação 2.1.2.(Notação científica)

O Python aceita notação científica. Por exemplo, 5.2×10−2 é representado da seguinte forma:

⬇
15.2e-2
⬇
0.052
Observação 2.1.3.(Casting)

Quando não há ambiguidade, pode-se fazer a conversão entre objetos de classes diferentes (casting). Por exemplo:

⬇
1x = 1
2print(x, type(x))
⬇
1 <class 'int'>
⬇
1y = float(x)
2print(y, type(y))
⬇
1.0 <class 'float'>

Além de objetos numéricos e string, Python também conta com objetos list (lista), tuple (n-upla) e dict (dicionário). Estudaremos essas classes de objetos mais adiante no minicurso.
