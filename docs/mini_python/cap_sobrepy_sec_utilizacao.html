1.2 Utilização

A execução de código em Python pode ser feita de três formas básicas:

  • •

    em modo interativo, em um console ou notebook Python;

  • •

    por execução de um script (por exemplo, arqnome.py) em um console ou notebook Python;

  • •

    por execução de um script (por exemplo, arqnome.py) em um terminal do sistema operacional.

Exemplo 1.2.1.

Consideremos o seguinte pseudocódigo.

s = "Olá, Mundo!"
imprime(s)  (imprime a string s)

Vamos transcrevê-lo em Python e executá-lo:

  1. a)

    Em um notebook.

    Iniciamos um notebook de Python e digitamos o seguinte código em uma célula de entrada:

    ⬇
    1s = "Olá, Mundo!"
    2# imprime a string s
    3print(s)

    Ao executarmos a célula, obtemos a saída:

    ⬇
    Olá, Mundo!
  2. b)

    Em modo interativo no console.

    Iniciamos um console Python no terminal do sistema e digitamos

    $ python3

    Aqui, o símbolo $ representa o prompt do sistema (vamos usar a notação do sistema operacional Linux). Em seguida, digitamos:

    ⬇
    1>>> s = "Olá, Mundo!"
    2>>> print(s) # imprime a string s

    O símbolo >>> é o prompt do console Python. A saída:

    ⬇
    Olá, Mundo!

    aparece abaixo da última linha executada. Para encerrar o console, digitamos:

    ⬇
    1>>> quit()
  3. c)

    Escrevendo o código ola.py e executando-o em um console/notebook.

    Escrevemos o código em uma IDE ou editor de texto:

    ⬇
    1s = "Olá, Mundo!"
    2print(s) # imprime a string s

    Uma vez salvo em /caminho/ola.py, executamos no console/notebook de Python com:

    ⬇
    1>>> exec(open('/caminho/ola.py').read())

    A saída é impressa logo abaixo do prompt/célula de entrada.

  4. d)

    Escrevendo o código ola.py e executando-o em terminal do sistema.

    Assumindo que o código esteja salvo em /caminho/ola.py, executamo-lo no terminal com:

    ⬇
    1$ python3 /caminho/ola.py

    A saída aparecerá no terminal do sistema operacional.

E. 1.2.1.

Modifique o código do exemplo anterior para que a saída seja uma saudação personalizada, como Olá, Pedro! ou Olá, Lays!.


⬇
1nome = 'Lays' # ou 'Pedro', ou outro nome
2print(f'Olá, {nome}!') # imprime a string s
E. 1.2.2.

O método input permite que a/o usuária/o digite uma mensagem no console/notebook. Por exemplo, o código a seguir solicita que a/o usuária/o digite seu nome e imprime uma saudação personalizada:

⬇
1nome = input('Digite seu nome: ')
2print(f'Olá, {nome}!')

Adicione ao código acima uma pergunta sobre a área acadêmica de interesse da/o usuária/o e imprima uma mensagem personalizada com base na resposta.


⬇
1nome = input('Digite seu nome: ')
2print(f'Olá, {nome}!')
3area = input('Digite sua área acadêmica de interesse: ')
4print(f'Interessante! A área de {area} é fantástica.')
