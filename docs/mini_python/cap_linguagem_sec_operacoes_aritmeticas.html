2.2 Operações aritméticas elementares

Os operadores aritméticos elementares são:

  • + adição

  • - subtração

  • * multiplicação

  • / divisão

  • ** potenciação

  • % módulo

  • // divisão inteira

Exemplo 2.2.1.

Estudamos a seguinte computação:

⬇
12+8*3/2**2-1
⬇
7.0

Observamos que a operação ** tem precedência sobre as operações *, /, %, //, as quais têm precedência sobre as operações + e -. Operações de mesma precedência seguem a ordem da esquerda para a direita, conforme escritas na linha de comando. Usam-se parênteses para alterar a precedência entre as operações, por exemplo:

⬇
1(2+8*3)/2**2-1
⬇
5.5

O operador % (módulo) computa o resto da divisão, e o operador // computa a divisão inteira. Por exemplo:

⬇
15 % 2
⬇
1
⬇
15 // 2
⬇
2
Observação 2.2.1.(Precedência das operações)

Consulte mais informações sobre a precedência de operadores em Python Docs: Operator Precedence. As operações acima mencionadas seguem a seguinte ordem de precedência (da maior para a menor):

  • ** (potenciação)

  • +x, -x (positivo, negativo)

  • *, /, %, // (multiplicação, divisão, módulo, divisão inteira)

  • +, - (adição, subtração)
