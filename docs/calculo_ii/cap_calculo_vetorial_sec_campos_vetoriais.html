4.3 Campos vetoriais

Um campo vetorial é uma função que associa a cada ponto de uma região do espaço um único vetor. Em duas dimensões, temos que campos vetoriais são funções da forma

𝑭⁢(x,y)=f1⁢(x,y)⁢𝒊+f2⁢(x,y)⁢𝒋, (4.59)

onde f1 e f2 são funções reais de duas variáveis. Em três dimensões, temos que campos vetoriais são funções da forma

𝑭⁢(x,y,z)=f1⁢(x,y,z)⁢𝒊+f2⁢(x,y,z)⁢𝒋+f3⁢(x,y,z)⁢𝒌, (4.60)

onde f1, f2 e f3 são funções reais de três variáveis.

Exemplo 4.3.1.

  1. a)

    𝑭⁢(x,y)=y⁢𝒊−x⁢𝒋

    Este campo vetorial é definido em todo o plano x⁢y e associa a cada ponto (x,y) o vetor (y,−x). A Figura 4.5 mostra o gráfico deste campo vetorial.

  2. b)

    𝑭⁢(x,y,z)=−y⁢𝒊+x⁢𝒋+z⁢𝒌

    Este campo vetorial é definido em todo o espaço e associa a cada ponto (x,y,z) o vetor (−y,x,z). A Figura 4.6 mostra o gráfico deste campo vetorial.

4.3.1 Campo gradiente

O campo gradiente de uma função real de duas ou três variáveis é o campo vetorial formado pelas derivadas parciais da função. Em duas dimensões, o campo gradiente de uma função f⁢(x,y) é

∇f⁢(x,y)=∂f∂x⁢(x,y)⁢𝒊+∂f∂y⁢(x,y)⁢𝒋, (4.61)

enquanto que em três dimensões, o campo gradiente de uma função f⁢(x,y,z) é

∇f⁢(x,y,z)=∂f∂x⁢(x,y,z)⁢𝒊+∂f∂y⁢(x,y,z)⁢𝒋+∂f∂z⁢(x,y,z)⁢𝒌. (4.62)
Exemplo 4.3.2.

O campo gradiente da função f⁢(x,y)=x2+y2 é

∇f⁢(x,y)=2⁢x⁢𝒊+2⁢y⁢𝒋. (4.63)

A Figura 4.7 mostra o gráfico do campo gradiente ∇f⁢(x,y)=2⁢x⁢𝒊+2⁢y⁢𝒋 e as curvas de nível da função f⁢(x,y)=x2+y2. O gradiente é perpendicular à curva de nível nos pontos em que não se anula.

4.3.2 Campos conservativos

Dizemos que um campo vetorial 𝑭 é conservativo se for o campo gradiente de uma função real ϕ, i.e. se existir uma função ϕ tal que

𝑭=∇ϕ. (4.64)

Quando existe, a função ϕ é chamada de função potencial do campo vetorial 𝑭.

Exemplo 4.3.3.(Campos de quadrado inverso)

Campos de quadrado inverso são campos vetoriais conservativos. Por exemplo, é conservativo o campo vetorial

𝑭⁢(𝒓)=c‖𝒓‖3⁢𝒓, (4.65)

onde c é uma constante, 𝒓=x⁢𝒊+y⁢𝒋 é o vetor posição e 𝒓≠𝟎. De fato, no domínio ℝ2∖{𝟎}, podemos escrever 𝑭⁢(𝒓) como o gradiente da função potencial

ϕ⁢(𝒓)=−c‖𝒓‖. (4.66)

Verifique!

4.3.3 Divergente e rotacional

O divergente de um campo vetorial 𝑭⁢(x,y,z)=f1⁢(x,y,z)⁢𝒊+f2⁢(x,y,z)⁢𝒋+f3⁢(x,y,z)⁢𝒌 é a função real definida por222O divergente de um campo vetorial 𝑭 também é denotado por div⁡𝑭.

∇⋅𝑭⁢(x,y,z)=∂f1∂x⁢(x,y,z)+∂f2∂y⁢(x,y,z)+∂f3∂z⁢(x,y,z). (4.67)

Notemos que ∇ define o operador diferencial

∇=∂∂x⁢𝒊+∂∂y⁢𝒋+∂∂z⁢𝒌. (4.68)

Com isso, o divergente de um campo vetorial 𝑭 é o produto escalar do operador ∇ com o campo vetorial 𝑭.

O rotacional de um campo vetorial 𝑭⁢(x,y,z)=f1⁢(x,y,z)⁢𝒊+f2⁢(x,y,z)⁢𝒋+f3⁢(x,y,z)⁢𝒌 é o campo vetorial definido por333O rotacional de um campo vetorial 𝑭 também é denotado por rot⁡𝑭.

∇×𝑭=[𝒊𝒋𝒌∂∂x∂∂y∂∂zf1f2f3] (4.69)
=(∂f3∂y−∂f2∂z)𝒊+(∂f1∂z−∂f3∂x)𝒋
+(∂f2∂x−∂f1∂y)⁢𝒌. (4.70)
Exemplo 4.3.4.

Vamos calcular o divergente e o rotacional do campo vetorial

𝑭⁢(x,y,z)=x⁢y2⁢𝒊+2⁢y⁢z⁢𝒋−x⁢z2⁢𝒌. (4.71)

O divergente de 𝑭 é

∇⋅𝑭=∂∂x⁢(x⁢y2)+∂∂y⁢(2⁢y⁢z)+∂∂z⁢(−x⁢z2) (4.72)
=y2+2z−2xz. (4.73)

O rotacional de 𝑭 é

∇×𝑭=[𝒊𝒋𝒌∂∂x∂∂y∂∂zx⁢y22⁢y⁢z−x⁢z2] (4.74)
=(∂∂y(−xz2)−∂∂z(2yz))𝒊+(∂∂z(xy2)−∂∂x(−xz2))𝒋
+(∂∂x⁢(2⁢y⁢z)−∂∂y⁢(x⁢y2))⁢𝒌 (4.75)
=(0−2y)𝒊+(0−(−z2))𝒋+(0−2xy)𝒌 (4.76)
=−2y𝒊+z2𝒋−2xy𝒌. (4.77)

4.3.4 Laplaciano

O operador laplaciano444Pierre-Simon Laplace, 1749 - 1827, matemático francês. Fonte: Wikipédia: Pierre-Simon Laplace. é definido como o divergente do gradiente de uma função real f⁢(x,y,z), i.e.

∇2f=∇⋅(∇f) (4.78)
=∂2f∂x2+∂2f∂y2+∂2f∂z2. (4.79)
Exemplo 4.3.5.

Vamos calcular o laplaciano da função f⁢(x,y,z)=x2+y2+z2. Temos que

∇f=2⁢x⁢𝒊+2⁢y⁢𝒋+2⁢z⁢𝒌, (4.80)
∇2f=∇⋅(∇f) (4.81)
=∂∂x(2x)+∂∂y(2y)+∂∂z(2z)=6. (4.82)

Mostre que o campo vetorial

𝑭⁢(x,y,z)=(2⁢x⁢y+z)⁢𝒊+(x2+2⁢y)⁢𝒋+x⁢𝒌 (4.84)

é conservativo e determine uma função potencial.


O campo é conservativo, pois 𝑭=∇ϕ para ϕ⁢(x,y,z)=x2⁢y+x⁢z+y2+C, onde C é uma constante.

𝑭⁢(x,y,z)=x2⁢y⁢𝒊+y⁢z2⁢𝒋+x⁢z⁢𝒌. (4.85)

∇⋅𝑭=2⁢x⁢y+z2+x
